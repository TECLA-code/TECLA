# ⚡ Inici Ràpid - TECLA Blocks

## 🚀 Executar TECLA Blocks (3 opcions)

### 1. 🖱️ Doble-Click (Més Fàcil)
```
Doble-click a: "TECLA Blocks.command"
```
**Primera vegada:** Click dret → Obrir → Confirmar

---

### 2. 💻 Terminal (Recomanat)
```bash
cd ~/Desktop/TECLA-Blocks
./start.sh
```

---

### 3. 📦 npm (Clàssic)
```bash
cd ~/Desktop/TECLA-Blocks
npm start
```

---

## 🔧 Si és la Primera Vegada

### Instal·lar Node.js
```bash
# Opció A: Homebrew
brew install node

# Opció B: Descarregar
# https://nodejs.org/
```

### Instal·lar Dependències
```bash
cd ~/Desktop/TECLA-Blocks
npm install
```

---

## 🎯 Ús Bàsic

1. **Crear programa:**
   - Arrossega blocs des del panell esquerre
   - Connecta'ls per crear el teu programa

2. **Veure codi:**
   - El codi Python es genera automàticament
   - Visible al panell dret

3. **Pujar a TECLA:**
   - Connecta TECLA via USB
   - Click "⬆️ Pujar a TECLA"
   - Segueix instruccions

4. **Executar:**
   - Desconnecta USB
   - Encén TECLA
   - Long press Botó 16 (1.5s)

---

## 🐛 Problemes Comuns

### "Permission denied"
```bash
chmod +x start.sh
chmod +x "TECLA Blocks.command"
```

### "command not found: node"
```bash
brew install node
```

### "Cannot find module"
```bash
npm install
```
