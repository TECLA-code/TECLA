1. Què és TECLA
TECLA és un projecte artístic, tecnològic i educatiu que busca, a través de la creació de dispositius electrònics, promoure la filosofia del DIY i del codi obert per investigar, experimentar i aprendre de diferents àrees del coneixement.
TECLA entén l’aprenentatge com quelcom transversal i interdisciplinari intricant la programació, el disseny, les arts plàstiques, el modelatge 3D, la música, la física, l’electrònica, la robòtica i les matemàtiques.


2. TECLA_edu
Aquesta app-web serveix principalment per configurar el dispositiu TECLA_edu com un instrument MIDI. A continuació es mostra pas a pas com funciona i quines són les seves característiques.
El TECLA_edu disposa de 16 tecles i 3 potenciòmetres. Envia notes MIDI per USB a qualsevol sintetitzador, DAW (Ableton, Logic, GarageBand…) o app de música. La sortida d’àudio emet una ona PWM.
Té dues grans capes: la capa Teclat (un instrument harmònic amb escales, acords, arpegiador, looper…) i la capa Modes (generadors musicals algorítmics: ones, clàssics, ritmes…).
Tot es configura des d’aquesta app web, sense instal·lar res: connecta el dispositiu per USB i prem connecta dispositiu.
Fes servir Chrome o Edge: l’app necessita l’accés a fitxers (File System Access) per escriure al dispositiu.






3. Posada en marxa
Connecta el TECLA a l’ordinador amb un cable USB de dades.
Si el disc que apareix es diu CIRCUITPY: ves a la pestanya Firmware → Instal·lar / Actualitzar firmware, espera el 100% i fes un reset al dispositiu. Llest.
Si el disc es diu RPI-RP2 (Pico nou de fàbrica): primer cal el CircuitPython. A Firmware, segueix el Pas 1; quan reaparegui com a CIRCUITPY, fes el Pas 2.
Per sentir-lo: obre el teu DAW o sintetitzador i selecciona el port MIDI TECLA com a entrada.
El nom del port USB i del disc es poden personalitzar a Modes → Identitat USB.

Tecles 1–8: notes de l’escala activa (o acords, si el mode acords està actiu).
Tecles 9–12, 14, 15: funcions reassignables des de la pestanya Teclat. Per defecte: escala, tonalitat, acords, arpegiador i octava ±.

Funcions assignables
𝄞 Escala: toc → següent escala · toc llarg → anterior. ♭ Tonalitat: cicla el cercle de quintes.
♪ Acords: toc → activar / ciclar tipus d’acord · toc llarg → desactivar. ≈ Arpegiador: toc → activar / ciclar patró · toc llarg → desactivar.
↕ Harmonia Negativa: reflecteix les notes sobre un eix harmònic. Δ Funcions Diatòniques: dominants secundàries, acords prestats, napolitans…
∞ Latch: les notes/acords continuen sonant en deixar anar; re-prémer un botó l’apaga; útil per drones.
𝆔 Conducció de veus: cada acord nou tria la inversió més propera a l’anterior — les progressions sonen lligades, com un pianista.
Potenciòmetres
3 pots amb dues capes de funcions (teclat i arpegiador), configurables des de l’app: velocity, modulació, sustain, gate, BPM de l’arp, CC Lliure (envia el CC MIDI que triïs, per controlar el teu synth)…






𝄆 Acompanyaments (Base)
La tecla amb la funció Base (acomp.) cicla els acompanyaments a cada toc (premuda llarga = aturar). Tots segueixen la tonalitat i l’escala del teclat en directe: primer els 4 integrats (Pols, Baix, Arpegi, Seqüència) i després els teus.
Crea’n de propis a Dispositiu → capa teclat → Acompanyaments: seqüències per graus de l’escala amb passos (4–16), octava (−2..+2), brillantor, velocitat (BPM propi) i durada de nota (picada → lligada).


5. Looper i Overdub
Dues funcions assignables que converteixen TECLA en una màquina de directe: ⟳ Looper (timing lliure) i ➕ Overdub (capes).
⟳ Gestos del looper
1r toc: armar (la gravació comença amb la primera nota) · 2n toc: el loop arrenca a l’instant.
Toc curt mentre sona: pausa / represa des del principi · Toc llarg (0,8 s): esborrar el loop.
El looper capta bé l’arpegiador: activa l’arp, arma el looper i el patró es grava sol. Si l’arp ha sonat durant la presa, el loop s’auto-quantitza a la graella de l’arp (captura fina, sense desfasament); si només graves acords/notes manuals, conserva el timing lliure exacte. Per canviar el tempo d’un loop d’arp: pausa → mou el pot de BPM → represa.
Si graves amb el sustain del pot actiu, el loop fixa el sustain a la gravació (les notes queden lligades): sona sostingut per si mateix i és independent del sustain en directe — pots abaixar el sustain per tocar notes seques a sobre sense que el loop s’alteri.
➕ Overdub (capes)
Toc curt amb el loop sonant: entrar/sortir del mode overdub — tot el que toquis s’afegeix al loop com una capa nova.
Toc llarg (0,8 s): desfer l’última capa (repeteix per anar pelant capes).
Toc molt llarg (1,6 s): esborrar TOTES les capes de cop — el loop base es manté.
Flux típic: grava una progressió d’acords → overdub d’una melodia → overdub de l’arp → toca en directe per sobre. La tecla 16 pausa el loop sense esborrar-lo.






6. La capa Modes
S’hi arriba ciclant amb la tecla 13. Les tecles 1–12 activen els modes generatius assignats a la capa actual.
Tecla 13: toc curt → capa següent · mantinguda ≈1 s → capa anterior.
Tecles 14 i 15: efectes temporals (mantenir premuda: sustain, pausa, gate…) · doble clic → canviar l’efecte assignat.
Tecla 16: STOP total + neteja de memòria.
Els modes es trien i s’assignen a la pestanya Modes; els potenciòmetres modulen paràmetres propis de cada mode.






7. Configurar des de l’app
Pestanya Teclat
Arrossega funcions a les tecles, tria escales, tonalitats, tipus d’acord, patrons d’arpegiador, progressions i funcions dels potenciòmetres.
Pestanya Modes
Crea bancs (capes) de modes i assigna un mode a cada tecla 1–12. Tria els efectes temporals de les tecles 14–15.
✦ Crear els teus propis modes
El botó ✦ Crear obre el constructor de modes. Els 64 modes del firmware es reparteixen en sis famílies segons com estan fets per dins, i cada família té les seves variables: melòdic (seqüència de graus sobre una escala), rítmic (graella de passos amb bateria), drone (acord sostingut amb gate), textura (atzar amb densitat), ona (un oscil·lador lent) i algorísmic (una regla que genera el patró).
A la família melòdica hi dibuixes la melodia per graus de l’escala en una graella, amb la dinàmica de cada pas, l’articulació (de picada a lligada), una veu secundària a l’interval que vulguis —el contrapunt de Bach, el tintinnabuli de Pärt— i el rang de tempo. També hi assignes què fa cada un dels tres potes.
A la família rítmica hi tens una graella de passos (8, 16 o 32; cada pas és una semicorxera, o sigui que 16 són un compàs de 4/4) amb cinc pistes de percussió i una línia de baix per graus. De cada pista en tries la nota MIDI, la força i la capa de breakdown —l’ordre en què les pistes es retiren amb el pot, el recurs de tot el techno—, i del conjunt, el rang de BPM i el swing. La percussió surt pel canal MIDI 10 (bateria General MIDI) i el baix pel canal 1, per posar-hi instruments diferents al DAW.
A la família drone hi munta les veus de l’acord triant-les casella a casella sobre dues octaves de semitons (o d’un clic amb les preses: quinta, major, menor, Dom7, Maj7, sus, dim, obert), amb quatre bancs que el pot cicla. I hi tries el moviment: Gate és una ona quadrada i el drone batega, Arc un triangle com un ale d’arquet i Respiració el mateix triangle suavitzat. El moviment pot anar a l’expressió, a la brillantor, al volum o a la modulació, amb el període i la profunditat que vulguis — al 100% el drone arriba a callar del tot a cada cicle.
Prem ▶ Escoltar per provar-lo a l’instant (corre el mateix Python que correrà al dispositiu), Desar mode per afegir-lo a la teva llista —i al dispositiu, si el tens endollat— o Exportar .py per quedar-te el fitxer. El mode generat és un fitxer de Python normal que pots obrir i modificar: l’especificació hi queda desada a dins, així que sempre el pots tornar a obrir al constructor.
Pestanya Simulador
Prova-ho tot sense dispositiu: el teclat i els modes corren al navegador i envien MIDI via WebMIDI al teu DAW.
Amb el dispositiu endollat, prem 🔌 Sync dispositiu: les tecles i potes físics controlen el simulador (el port es detecta sol; el so local del TECLA es pausa mentre dura).
La Pantalla
El botó Pantalla (capçalera) obre la pantalla virtual del dispositiu: mostra en gran i en directe què toques — acords amb nomenclatura professional (C, Am7, F/A…), notes, funcions amb el seu color, canvis de capa — amb una animació reactiva als potes pròpia de cada família de modes.
El tempo hi surt en BPM — negres per minut, el mateix número que poses al DAW o al metrònom — per poder sincronitzar amb la peça que estàs tocant. L’etiqueta hi afegeix la subdivisió quan cal: «Tempo · 1/16» vol dir que el que sona són semicorxeres d’aquest tempo. L’animació batega al mateix pols.
El pot de BPM de l’arpegiador va de 40 a 240 negres per minut i l’arp trepitja semicorxeres: posa el mateix número que el teu projecte i ja hi encaixa.
Es connecta sola al port sèrie correcte, es pot arrossegar i redimensionar, i amb ⇱ es desancora en una finestra flotant fora de l'app (Chrome 116+).
Pestanya Firmware
Instal·la CircuitPython (Pas 1) i el firmware TECLA (Pas 2). Cal repetir el Pas 2 després de canviar els modes assignats.
Pestanya Aparença
Temes de color de l’app i editor de temes personalitzats.
Flux de treball: edita → Guardar configuració → si has canviat modes, Firmware → Instal·lar / Actualitzar → reset del dispositiu.






8. Recomanacions
Guarda sempre la configuració després de fer canvis.
Fins a 3 bancs de modes funcionen amb total comoditat (validat amb mesures de memòria reals).
Prova els modes nous al simulador abans d’instal·lar-los.
Si una nota es queda penjada o el so descontrola: tecla 16 (STOP).
Si el dispositiu no respon: reset físic (botó del Pico) — el watchdog també el reinicia sol si es penja durant una actuació.
Si l’app no veu el dispositiu: comprova que el disc CIRCUITPY/TECLA està muntat i que fas servir Chrome o Edge.

4. Looper y Overdub
Dos funciones asignables: ⟳ Looper (timing libre) y ➕ Overdub (capas).
⟳ Gestos del looper
1er toque: armar (la grabación empieza con la primera nota) · 2º toque: el loop arranca al instante.
Toque corto mientras suena: pausa / reanudar desde el principio · Toque largo (0,8 s): borrar el loop.
El looper capta bien el arpegiador: activa el arp, arma el looper y el patrón se graba solo. Si el arp ha sonado durante la toma, el loop se auto-cuantiza a la rejilla del arp (captura fina, sin desfase); si solo grabas acordes/notas manuales, conserva el timing libre exacto. Para cambiar el tempo de un loop de arp: pausa → mueve el pot de BPM → reanuda.
Si grabas con el sustain del pot activo, el loop fija el sustain en la grabación (las notas quedan ligadas): suena sostenido por sí mismo y es independiente del sustain en directo — puedes bajar el sustain para tocar notas secas encima sin que el loop se altere.
➕ Overdub (capas)
Toque corto con el loop sonando: entrar/salir del modo overdub — lo que toques se añade al loop como una capa nueva.
Toque largo (0,8 s): deshacer la última capa (repite para ir pelando capas).
Toque muy largo (1,6 s): borrar TODAS las capas de golpe — el loop base se mantiene.
Flujo típico: graba una progresión → overdub de una melodía → overdub del arp → toca en directo encima. La tecla 16 pausa el loop sin borrarlo.






5. La capa Modos
Se entra con la tecla 13 (toque corto). Las teclas 1–12 activan los modos generativos del banco actual.
Tecla 13 mantenida ≈1 s: cambia de banco de modos (Capa 1 → Capa 2 → Capa 3…).
Teclas 14 y 15: efectos temporales (mantener pulsada: sustain, pausa, gate…) · doble clic → cambiar el efecto.
Tecla 16: STOP total + limpieza de memoria.
Los modos se eligen y asignan en la pestaña Modos; los potenciómetros modulan parámetros propios de cada modo.






6. Configurar desde la app
Pestaña Teclado
Arrastra funciones a las teclas, elige escalas, tonalidades, tipos de acorde, patrones de arpegiador, progresiones y funciones de los potenciómetros.
Pestaña Modos
Crea bancos (capas) de modos y asigna un modo a cada tecla 1–12. Elige los efectos temporales de las teclas 14–15.
Pestaña Simulador
Pruébalo todo sin dispositivo: el teclado y los modos corren en el navegador y envían MIDI vía WebMIDI a tu DAW.
Pestaña Firmware
Instala CircuitPython (Paso 1) y el firmware TECLA (Paso 2). Repite el Paso 2 tras cambiar los modos asignados.
Pestaña Apariencia
Temas de color de la app y editor de temas personalizados.
Flujo de trabajo: edita → Guardar configuración → si cambiaste modos, Firmware → Instalar / Actualizar → reset del dispositivo.






7. Recomendaciones
Guarda siempre la configuración tras hacer cambios.
Hasta 3 bancos de modos funcionan con total comodidad (validado con medidas de memoria reales).
Prueba los modos nuevos en el simulador antes de instalarlos.
Si una nota se queda colgada: tecla 16 (STOP).
Si el dispositivo no responde: reset físico (botón del Pico) — el watchdog también lo reinicia solo si se cuelga.
Si la app no ve el dispositivo: comprueba que el disco CIRCUITPY/TECLA está montado y que usas Chrome o Edge.

1. What is TECLA
TECLA is an artistic, technological and educational project that promotes the DIY and open-source philosophy through the creation of electronic devices, as a way to research, experiment and learn across fields: programming, design, visual arts, 3D modelling, music, physics, electronics, robotics and mathematics.
TECLA_edu
This web app is mainly used to set up the TECLA_edu device as a MIDI instrument: 16 keys and 3 knobs. It sends MIDI notes over USB to any synthesizer, DAW (Ableton, Logic, GarageBand…) or music app. The audio output is a PWM wave.
It has two main layers: the Keyboard layer (a harmonic instrument with scales, chords, arpeggiator, looper…) and the Modes layer (algorithmic music generators).
Everything is configured from this web app, nothing to install: plug the device in via USB and press connect device.
Use Chrome or Edge: the app needs File System Access to write to the device.






2. Getting started
Connect TECLA to your computer with a USB data cable.
If the disk is named CIRCUITPY: go to Firmware → Install / Update firmware, wait for 100% and reset the device. Done.
If the disk is named RPI-RP2 (factory-fresh Pico): install CircuitPython first. In Firmware, follow Step 1; once it reappears as CIRCUITPY, do Step 2.
To hear it: open your DAW or synth and select the TECLA MIDI port as input.
The USB port and disk names can be customised in Modes → USB Identity.

Keys 1–8: notes of the active scale (or chords, when chord mode is on).
Keys 9–12, 14, 15: functions reassignable from the Keyboard tab. Defaults: scale, key, chords, arpeggiator and octave ±.
Key 13 (fixed): short press → switch to the Modes layer · hold ≈1 s → switch mode bank.
Key 16 (fixed): STOP — kills all sound.
Assignable functions
𝄞 Scale: tap → next · long press → previous. ♭ Key: cycles the circle of fifths.
♪ Chords: tap → enable / cycle chord type · long → disable. ≈ Arpeggiator: tap → enable / cycle pattern · long → disable.
↕ Negative Harmony: mirrors notes across a harmonic axis. Δ Diatonic Functions: secondary dominants, borrowed chords, Neapolitans…
∞ Latch: notes/chords keep sounding after release; press again to stop them; great for drones.
𝆔 Voice leading: each new chord picks the inversion closest to the previous one — progressions flow like a pianist’s.
Knobs
3 pots with per-layer functions (normal, arpeggiator, chords, neg. harmony): velocity, modulation, sustain, gate, arp BPM, inversions, Free CC (send any MIDI CC you choose)…






4. Looper & Overdub
Two assignable functions: ⟳ Looper (free timing) and ➕ Overdub (layers).
⟳ Looper gestures
1st tap: arm (recording starts with your first note) · 2nd tap: the loop starts instantly.
Short tap while playing: pause / resume from the top · Long press (0.8 s): clear the loop.
The looper captures the arpeggiator tightly: enable the arp, arm the looper and the pattern records itself. If the arp played during the take, the loop auto-quantizes to the arp grid (tight capture, no drift); if you only record manual chords/notes, it keeps the exact free timing. To change an arp loop's tempo: pause → move the BPM pot → resume.
If you record with the sustain pot active, the loop bakes the sustain into the recording (notes become legato): it sounds sustained on its own and is independent of the live sustain — you can lower the sustain to play dry notes on top without altering the loop.
➕ Overdub (layers)
Short tap while the loop plays: enter/exit overdub mode — whatever you play is added to the loop as a new layer.
Long press (0.8 s): undo the last layer (repeat to peel layers off one by one).
Very long press (1.6 s): wipe ALL layers at once — the base loop survives.
Typical flow: record a chord progression → overdub a melody → overdub the arp → play live on top. Key 16 pauses the loop without erasing it.






5. The Modes layer
Enter it with key 13 (short press). Keys 1–12 trigger the generative modes of the current bank.
Key 13 held ≈1 s: switches mode bank (Layer 1 → Layer 2 → Layer 3…).
Keys 14 & 15: temporary effects (hold: sustain, pause, gate…) · double-click → change the assigned effect.
Key 16: full STOP + memory cleanup.
Modes are chosen and assigned in the Modes tab; the knobs modulate each mode’s own parameters.






6. Configuring from the app
Keyboard tab
Drag functions onto keys; pick scales, keys, chord types, arpeggiator patterns, progressions and pot functions.
Modes tab
Create mode banks (layers) and assign a mode to each key 1–12. Choose the temporary effects for keys 14–15.
Simulator tab
Try everything without the device: the keyboard and modes run in the browser and send MIDI via WebMIDI to your DAW.
Firmware tab
Install CircuitPython (Step 1) and the TECLA firmware (Step 2). Repeat Step 2 after changing assigned modes.
Appearance tab
App colour themes and a custom theme editor.
Workflow: edit → Save settings → if you changed modes, Firmware → Install / Update → reset the device.






7. Tips
Always save your settings after making changes.
Up to 3 mode banks run comfortably (validated with real memory measurements).
Test new modes in the simulator before installing them.
Stuck note or runaway sound: key 16 (STOP).
Device unresponsive: physical reset (Pico button) — the watchdog also auto-restarts it if it ever hangs live.
App can’t see the device: check the CIRCUITPY/TECLA disk is mounted and that you’re using Chrome or Edge.
