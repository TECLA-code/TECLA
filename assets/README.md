# Assets de TECLA Blocks

Aquest directori conté els recursos visuals de l'aplicació:

## Icones necessàries:

- **icon.png** (512x512) - Icona principal
- **icon.icns** (macOS)
- **icon.ico** (Windows)

## Com generar les icones:

1. Crear una imatge PNG de 1024x1024 amb el logo TECLA
2. Utilitzar eines com:
   - [electron-icon-builder](https://www.npmjs.com/package/electron-icon-builder)
   - [Icon Slate](https://www.kodlian.com/apps/icon-slate) (macOS)
   - Online: [iConvert Icons](https://iconverticons.com/)

## Disseny recomanat:

- Fons: Gradient blau (#2196F3 → #1976D2)
- Element central: Teclat musical + blocs de programació
- Estil: Modern, flat design
- Colors: Paleta TECLA (blau primari, colors Blockly)
