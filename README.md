# TECLA — apps web

Aquest repositori conté **contingut generat automàticament**: les apps web de
TECLA ja construïdes, tal com es publiquen a
<https://tecla-code.github.io/TECLA/>.

El codi font viu en un repositori privat i no es distribueix. Vegeu `LICENSE`:
les apps són propietàries; el codi del dispositiu (`codi/device_files/`) és
GPL-3.0.
