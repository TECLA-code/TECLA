## 🎯 Noves Categories i Blocs

### 1. ⚙️ **Control Avançat** (4 blocs)
Estructures de control més sofisticades:

- **Switch/Case** - Múltiples condicions elegants
- **Break** - Surt de bucles
- **Continue** - Salta a següent iteració
- **Try/Except** - Gestió d'errors professional

**Utilitat:** Programes més nets i robustos.

---

### 2. ⏰ **Temps i Temporitzadors** (5 blocs)
Control precís del temps:

- **Temps actual** - Segons des de l'inici
- **Mil·lisegons** - Temporització precisa
- **Iniciar temporitzador** - Cronòmetre personalitzat
- **Temps transcorregut** - Mesura durades
- **Dormir (ms)** - Pausa en mil·lisegons

**Utilitat:** Seqüenciadors, animacions, mesures de rendiment.

---

### 3. 📝 **String Avançat** (7 blocs)
Manipulació professional de text:

- **Replace** - Substituir text
- **Split** - Dividir en llista
- **Join** - Unir llista amb separador
- **Format** - Formatació de strings
- **Contains** - Comprova si conté
- **Starts with** - Comprova prefix
- **Ends with** - Comprova sufix

**Utilitat:** Parsing de dades, protocols de comunicació, UI.

---

### 4. 📐 **Matemàtiques Avançades** (8 blocs)
Funcions matemàtiques completes:

- **Sin, Cos, Tan** - Trigonometria
- **Log, Exp** - Logaritmes i exponencials
- **Radians ↔ Graus** - Conversions d'angles
- **Bitwise** - Operacions a nivell de bit (AND, OR, XOR, SHIFT)

**Utilitat:** Síntesi d'àudio, geometria, processament de senyals, protocols baixos nivell.

---

### 5. 💡 **NeoPixels / RGB LEDs** (5 blocs)
Control de tires LED RGB:

- **Configurar NeoPixels** - Setup de tira LED
- **Establir color** - RGB per LED individual
- **Actualitzar** - Mostra els canvis
- **Apagar tots** - Clear
- **Arc de Sant Martí** - Efecte rainbow automàtic

**Utilitat:** Visualitzacions, indicadors, art lumínic, feedback visual.

---

### 6. 🖥️ **Display OLED/LCD** (6 blocs)
Pantalles gràfiques i text:

- **Configurar Display** - OLED 128x64 o LCD 16x2
- **Mostrar text** - Text a posició X,Y
- **Netejar** - Clear screen
- **Pixel** - Dibuixa píxel
- **Línia** - Dibuixa línia
- **Rectangle** - Contorn o omplert

**Utilitat:** Visualització de dades, menús, gràfics, interfícies.

---

### 7. 🎛️ **Motors i Servos** (4 blocs)
Control de moviment:

- **Configurar Servo** - Setup servomotor
- **Angle Servo** - Mou a angle (0-180°)
- **Configurar Motor DC** - Setup motor amb H-bridge
- **Velocitat Motor** - Controla velocitat i direcció

**Utilitat:** Robòtica, instruments mecànics, automatitzacions.

---

### 8. 👁️ **Sensors Adicionals** (5 blocs)
Més tipus de sensors:

- **Sensor de llum** - Fotoresistència (0-100%)
- **Sensor de so** - Micròfon/amplitud (0-100%)
- **Sensor humitat** - Terra/ambient (0-100%)
- **Sensor PIR** - Detecció de moviment (True/False)
- **Botó extern** - GPIO amb pull-up/down

**Utilitat:** Monitoratge ambiental, interaccions, automatitzacions.

---

### 9. 📶 **PWM Avançat** (2 blocs)
Control PWM personalitzat:

- **PWM Configurar** - Freqüència personalitzada
- **Duty Cycle** - Control precís (0-100%)

**Utilitat:** Control de motors, LEDs, tons, síntesi.

---

### 10. 💾 **Emmagatzematge** (4 blocs)
Memòria persistent:

- **Guardar** - Key-value storage
- **Llegir** - Recuperar dades
- **Existeix** - Comprova clau
- **Eliminar** - Esborra dada

**Utilitat:** Configuracions, presets, logs, calibracions.

---

### 11. 🔧 **Sistema** (4 blocs)
Informació del sistema:

- **Reiniciar** - Soft reset del dispositiu
- **Memòria lliure** - Bytes disponibles
- **Temperatura CPU** - Monitoratge tèrmic
- **Voltatge bateria** - Nivell d'alimentació

**Utilitat:** Debugging, monitoratge, gestió d'energia.

## 💡 Exemples d'Ús

### Exemple 1: Termòmetre amb Display
```blockly
Configurar Display OLED
Repetir per sempre:
  ├─ temperatura = Temperatura CPU
  ├─ text = Format "Temp: {}" temperatura
  ├─ Mostrar text a 0, 0
  └─ Esperar 1s
```

### Exemple 2: Tira LED Rainbow
```blockly
Configurar NeoPixels pin 5, 30 LEDs
offset = 0
Repetir per sempre:
  ├─ Arc de Sant Martí offset
  ├─ offset = offset + 5
  └─ Esperar 0.05s
```

### Exemple 3: Robot amb Sensor
```blockly
Configurar Motor DC pins 10, 11
Configurar Sensor PIR pin 15
Repetir per sempre:
  ├─ Si Sensor PIR:
  │   └─ Motor velocitat 50 Endavant
  ├─ Sinó:
  │   └─ Motor Aturar
  └─ Esperar 0.1s
```

### Exemple 4: Seqüenciador amb Temporitzador
```blockly
Iniciar temporitzador t
notes = [60, 64, 67, 72]
Repetir per sempre:
  ├─ Per cada nota en notes:
  │   ├─ Tocar nota
  │   └─ Esperar 0.25s
  ├─ Si temps transcorregut t > 10:
  │   └─ Break
```

## 🔌 Hardware Compatible

### TECLA Device
✅ Tot funciona nativamente

### Extensions Compatibles
- **NeoPixels** - Tires WS2812B, SK6812
- **OLED** - SSD1306 I2C 128x64
- **LCD** - HD44780 I2C 16x2, 20x4
- **Servos** - SG90, MG90S, etc.
- **Motors DC** - Amb H-bridge L298N, DRV8833
- **Sensors:**
  - Llum: LDR, BH1750
  - So: MAX9814, Electret
  - Humitat: Capacitiu, resistiu
  - PIR: HC-SR501
  - Temperatura: LM35, DHT22, BME280
  - Distància: HC-SR04 (ja suportat)
