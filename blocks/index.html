1. Primers passos

Connecta el TECLA a l'ordinador via USB-C.

Si és la primera vegada, instal·la CircuitPython (pestanya Firmware → Pas 1).

Instal·la la carpeta adafruit_midi a CIRCUITPY/lib/ (Pas 2).

El TECLA funciona com a interfície MIDI USB. No cal cap driver addicional a macOS i Linux.
2. Programar amb blocs

Arrossega blocs de la caixa d'eines a l'espai de treball.

Encaixa els blocs per crear el teu programa musical.

El codi CircuitPython es genera automàticament a la pestanya Codi.

Categories de blocs

Música Bàsica: Notes MIDI, acords, escales

Síntesi Avançada: Oscil·ladors, LFO, envelops

Control Hardware: Botons i potenciòmetres del TECLA

Efectes: Delay, reverb, filtres

GPIO: Pins digitals, PWM, analògics

Generatiu: Probabilitat, LFO per software, quantització

Scratch: Events, missatges, control de flux

3. Pujar al dispositiu

Prem Connectar al header i selecciona el volum CIRCUITPY.

Un cop connectat, prem Pujar per copiar el codi al dispositiu.

El TECLA s'executa automàticament en reiniciar-se.

Requereix Chrome o Edge (File System Access API). A Safari, exporta el .py i copia'l manualment a CIRCUITPY.

1Instal·lar CircuitPython

Entra al mode bootloader mantenint BOOTSEL mentre connectes el USB-C. El dispositiu apareixerà com RPI-RP2.

Obre el Finder → arrossega el fitxer .uf2 al volum RPI-RP2. El dispositiu es reiniciarà com CIRCUITPY.

Descarregar CircuitPython (.uf2)
2Instal·lar les llibreries

Descarrega el bundle de llibreries de CircuitPython i copia la carpeta adafruit_midi dins CIRCUITPY/lib/.

Cerca adafruit-circuitpython-bundle → descomprimeix → copia adafruit_midi/ a CIRCUITPY/lib/.

Descarregar Bundle de Llibreries
3Pujar el codi del projecte

Un cop CIRCUITPY és visible, connecta el dispositiu amb el botó Connectar del header i prem Pujar per copiar el codi.

El fitxer code.py es copia automàticament i el TECLA s'executa de nou.
