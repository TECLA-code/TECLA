Sistema operatiu

Sistema de l'ordinador on connectes el TECLA. S'usa per enviar símbols que no són al teclat (φ, π, €, emojis…) amb la seqüència d'entrada Unicode correcta.

Per als símbols Unicode cal un ajust únic al sistema de destí: a macOS, activa la font d'entrada Unicode Hex Input; a Windows, la clau de registre EnableHexNumpad=1. A Linux (IBus/GTK) funciona directament.

Pas 1 — Sistema base

Només cal la primera vegada. Connecta la placa mantenint premut BOOTSEL: apareixerà com a RPI-RP2. Tria aquest volum quan el diàleg t'ho demani.

Després del CircuitPython el dispositiu es reinicia sol i reapareix amb el seu nom de disc (CIRCUITPY per defecte). Llavors ja pots transferir-hi les llibreries.

Pas 2 — Actualitzar el firmware

Envia la teva configuració al dispositiu: es copia a personalitats/macropad.py i, si falten, també les llibreries.

Per canviar de TECLA: aguanta les quatre cantonades 3 segons i passa a la següent (Instrument → Macropad → Blocks). Si el dispositiu no respon a res, endolla’l amb les quatre premudes: deixa-les anar per anar a la següent, o aguanta-les 5 segons per tornar a l’Instrument.

Editor de temes

Mentre aquesta tecla és premuda, el modificador queda actiu. Permet combinar-lo amb qualsevol altra tecla (ex: ⊕ + ↓ per rotar en un RPG).

Envia un clic esquerre cada vegada que el potenciòmetre canvia N unitats (rang 0–127).

Escriu el text indicat cada vegada que el potenciòmetre avança N unitats: un text girant cap a l'esquerra i un altre cap a la dreta. Pots posar-hi qualsevol símbol (per exemple + i − per fer zoom).

Els símbols + − * / s'envien pel teclat numèric, així que surten igual sigui quina sigui la disposició de teclat de l'ordinador. Per fer zoom, combina'ls amb una tecla de tipus Modificador Mantingut (Cmd/Ctrl) si l'aplicació ho requereix. Per a símbols que no són al teclat (φ, π…), tria el teu sistema a Configuració.
Rang i corba

Aquesta tecla canviarà de capa al ser premuda.

Amb topall, la tecla deixa de fer efecte quan ja ets a la primera o a l'última capa: així sempre saps on ets encara que et perdis entre capes.

Obre una aplicació escrivint el seu nom al llançador del sistema (Spotlight a macOS, Menú Inici a Windows).

En prémer la tecla s'executen els passos en ordre. Un pas pot ser qualsevol funció de les tecles: drecera, text, multimèdia, ratolí, nota MIDI, obrir una aplicació o canviar de capa — i esperes entremig.

Cada «pas» del potenciòmetre executa una macro: una en girar a la dreta i una altra en girar a l'esquerra. Deixa-la buida si només vols que actuï en un sentit.
